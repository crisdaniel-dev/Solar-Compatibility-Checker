# Contributing to Solar-Compatibility-Checker

Thank you for your interest in contributing to **Solar-Compatibility-Checker**! Whether you are improving the original C command-line program, helping build the web version, or fixing typos in the documentation, every helpful contribution is appreciated.

## Step-by-Step Guide

### 1. Find or Open an Issue
- Check the **Issues** tab to see existing tasks or bugs (especially ones labeled `good first issue` or `help wanted`).
- If you want to work on an open issue, leave a brief comment letting everyone know you are picking it up before you start coding.
- If you have a new idea or spot a bug that isn't listed yet, open a new issue first so we can discuss the approach.

### 2. Fork and Clone the Repository
- Click the **Fork** button at the top right of this repository to create your own copy under your GitHub account.
- Clone your forked repository to your local machine:
  ```bash
  git clone [https://github.com/](https://github.com/)<your-username>/Solar-Compatibility-Checker.git
  cd Solar-Compatibility-Checker
